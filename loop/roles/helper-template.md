# Helper-bot template

Created by the CIO or CTO for one task. Copy this file to `loop/roles/helpers/<name>.md`.

- **Owner:** CIO | CTO
- **Task:** one sentence
- **Token budget:** N tokens
- **Expires:** YYYY-MM-DD
- **Inputs allowed:** list
- **Spend rights:** none
- **Output:** where the result is written

Max 3 helpers active at once. Helpers never hold keys and never change policy.
