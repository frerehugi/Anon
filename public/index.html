How it is built

One data core

An indexer reads x402 settlements and ERC-8004 registry events from Celo into a database. The metrics and the directory are two views of it, and every metric is labelled measured, estimated or unavailable.

Probes never pay

The directory asks each declared endpoint for its price with an unpaid request and records status, accepted tokens and payTo. Nothing is ever paid by the crawler.

Autonomy with limits

An agent team decides what to build and buy. A deterministic executor holds the only key, enforces an allowlist, limits and a kill switch, and writes an append-only ledger.
